# 仓库维护与分享说明

仓库地址：[YuanUser001/personal-paper-reader](https://github.com/YuanUser001/personal-paper-reader)。仓库设为公开，队员和评审可通过链接查看。使用方法见根目录README.md。

以下步骤用于维护者后续更新文件：

1. 登录有写入权限的GitHub账号，打开上述仓库。
2. 解压本地准备包，打开其中personal-paper-reader-github目录。确认README.md与skills位于这个目录的同一层。
3. 在GitHub仓库打开文件上传入口，上传该目录里面的README.md、skills、examples、docs、requirements.txt、VERSION和.gitignore，保留文件夹层级。不要只上传ZIP，也不要多包一层外部文件夹。
4. 在网页确认README.md位于仓库根目录，且存在skills/personal-paper-reader/SKILL.md，再写提交说明并保存。按钮名称和分支流程以当前GitHub界面为准。
5. 仓库形成实际地址后，将实际链接分享给使用者；安装时指明skills/personal-paper-reader。没有真实仓库地址前不填写虚构链接。

上传方法依据[GitHub官方文件上传说明](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)。
